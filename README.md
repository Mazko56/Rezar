# REZAR Telegram Bot

Обновлённая версия бота с постоянным нижним меню, квизом по авто, разделом доступа к аукционам,
менеджером и блоком «Чому авто з Кореї?».

## Что реализовано

- постоянное нижнее меню под строкой ввода;
- главное меню из 5 разделов;
- квиз для «Отримати варіанти авто» и «Розрахувати під ключ»;
- шаги квиза: пожелания → бюджет → срок покупки → город доставки → контакт → способ ответа;
- после передачи контакта кнопка `Поділитися контактом` больше не показывается;
- отдельный сценарий для `Зв'язок з менеджером`;
- отдельный сценарий для `Безкоштовні доступи до аукціонів`;
- многоэкранный раздел `Чому авто з Кореї?` с показом новых экранов ниже в ленте;
- загрузка изображений из папки `assets/`.

## Важно про первый экран до Start

Экран до нажатия `Розпочати` настраивается через `@BotFather`, а не кодом.
Для него использовать `assets/1.png` и текст описания бота.

## Папка с фото

Фото складывать в:

```text
assets/
```

Названия файлов описаны в `assets/README.txt`.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```
