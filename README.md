# REZAR Telegram Bot — Stage 1 fixed

## Правильная стартовая последовательность

### ДО нажатия «Розпочати»

Этот экран не отправляется Python-кодом. Его необходимо настроить в Telegram как Bot Intro:

**Текст:**

> Привіт! Це офіційний бот компанії REZAR — підберемо та доставимо авто з Південної Кореї з вигодою до 30% від ринку України, з гарантією прорахованої ціни, страхуванням ризиків та поетапною оплатою. Натисніть “СТАРТ” та оберіть, що вас цікавить.

**Фото:** `1.png`

Настройка выполняется через BotFather → `/mybots` → выбрать бота → **Edit Bot**:

- **Edit Description** — вставить текст выше;
- **Edit Description Picture / Edit Intro Media** — загрузить `1.png`;
- при необходимости **Edit About** и **Edit Botpic** настраиваются отдельно.

### ПОСЛЕ нажатия «Розпочати»

Код выполняет последовательность:

1. `2.png` + текст «Ласкаво просимо!...»;
2. ожидание 3 секунды;
3. `3.png` + «Тут буде текст презентації» — **без кнопок**;
4. отдельное сообщение:

   `Отже, оберіть нижче розділ, щоб ми могли швидше і точніше вам допомогти:`

   и кнопки главного меню.

В этой версии первое приветствие больше НЕ дублируется после `/start`.

## Почему раньше могло остановиться после второго сообщения

Если Telegram не принимал файл `3.png` (битый файл, неподдерживаемый файл, слишком большой файл и т.п.), обработчик `/start` мог остановиться на отправке изображения.

Теперь добавлен fallback: если фото не отправилось, бот отправляет текст и **всё равно показывает главное меню**.
