# REZAR Telegram Bot — Stage 1 (updated)

Первый этап: оболочка бота, все основные разделы, кнопки, переходы и квизовый цикл.

## Что обновлено

- приветственный текст обновлён;
- после `/start` бот отправляет:
  1. приветствие;
  2. вводный текст;
  3. через 3 секунды мини-презентацию без кнопок;
  4. отдельным сообщением главное меню с кнопками;
- фото теперь подтягиваются не из переменных окружения, а из папки `assets/`;
- для фото используется формат `1.png`, `2.png`, `3.png` и т.д.

## Важно про экран ДО нажатия «Старт»

Сообщение, которое пользователь видит **до** нажатия кнопки `Start/Розпочати`, не отправляется кодом бота.
Это настраивается отдельно через **BotFather**:

- `/setdescription`
- `/setabouttext`
- `/setuserpic`

То есть стартовый экран до нажатия кнопки нужно оформить в BotFather, а всё остальное уже делает сам бот после `/start`.

## Куда загружать фото

Фото нужно складывать в папку:

```text
assets/
```

Названия файлов:

- `1.png` — приветствие
- `2.png` — вводный экран
- `3.png` — мини-презентация
- `4.png` — Підібрати авто
- `5.png` — после формирования запроса
- `6.png` — после контакта
- `7.png` — Аукціони
- `8.png` — Дилери
- `9.png` — Розрахувати під ключ
- `10.png` — Карта доступів 1
- `11.png` — Карта доступів 2
- `12.png` — Карта доступів 3
- `13.png` — Чому Корея 1
- `14.png` — Чому Корея 2
- `15.png` — Чому Корея 3
- `16.png` — Менеджер

Если файла нет — бот отправляет только текст.

## Что пока не включено

Это всё ещё первый этап, поэтому пока нет:

- PostgreSQL
- CRM
- Graspil
- retry-очереди
- backup БД
- `/admin`

## Локальный запуск

```bash
python -m venv .venv
pip install -r requirements.txt
python -m app.main
```

Нужен только `BOT_TOKEN` в `.env`.
